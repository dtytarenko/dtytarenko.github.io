# Portfolio - Dmytro Tytarenko

Modern portfolio website built with cutting-edge technologies and optimized for performance.

## 🚀 Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Fast build tool
- **Three.js** - 3D graphics
- **Framer Motion** - Animations
- **Swiper** - Touch slider
- **React Hook Form** - Form management
- **SCSS Modules** - Styling
- **Inter Font** - Typography

## ✨ Features

- ⚡ Optimized for Google PageSpeed Insights
- 🎨 Modern design with smooth animations
- 🎮 Interactive Three.js background
- 📱 Fully responsive
- ♿ Accessibility-friendly
- 🔍 SEO optimized
- 📦 Code splitting & lazy loading
- 🔧 PWA ready
- 🚀 Deployed to GitHub Pages

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Lint code
npm run lint
```

## 📦 Deployment

This project is automatically deployed to GitHub Pages using GitHub Actions.

Push to `master` branch to trigger deployment:

```bash
git add .
git commit -m "Update portfolio"
git push origin master
```

## 🎯 Performance Optimizations

- **Code Splitting**: Components lazy-loaded for better initial load
- **Image Optimization**: Images loaded with lazy loading
- **PWA**: Service Worker for offline functionality
- **Font Optimization**: Self-hosted Inter font
- **Bundle Size**: Manual chunks for optimal loading
- **Tree Shaking**: Unused code eliminated
- **Minification**: CSS and JS minified
